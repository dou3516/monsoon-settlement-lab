# 风与聚落

面向初中地理“做中学”的交互式网页实验工具。通过调整聚落周边的树木、水域布局和气象条件，比较不同方案的模拟降温效果，探索风向与空间布局之间的关系。

## 在线使用

**[打开风与聚落](https://dou3516.github.io/monsoon-settlement-lab/)**

无需安装，直接在浏览器中使用。

## 可以做什么

- 调整树木、水域布局，比较不同方案。
- 设置风向、风速等气象条件，运行模拟并查看结果。
- 导入 JSON 实验文件，导出 PNG 图像和 CSV 数据。
- 在页面中查看模型说明与适用范围。

## 本地使用

下载本仓库并解压，用浏览器打开 `index.html` 即可。网页使用 HTML、CSS 和 JavaScript，计算在浏览器本地完成，无需后端服务。

## 适用范围

本工具用于课堂探究和方案比较。温差与蒸发耗水属于探索性参数下的教学模拟，未经实地校准，不宜直接作为实际规划或工程设计依据。详细说明见网页中的“模型说明”或 [methods.html](https://dou3516.github.io/monsoon-settlement-lab/methods.html)。

本仓库保存可直接部署的网页文件。
